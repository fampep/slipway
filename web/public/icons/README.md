# App icons

Icons are pulled from these GitHub projects (not custom-drawn):

- https://github.com/walkxcode/dashboard-icons (Jellyfin, Plex, Emby, Sonarr, Radarr, Prowlarr, qBittorrent, Filebrowser)
- https://github.com/homarr-labs/dashboard-icons (Silo Server)

Local copies under web/public/icons/ are cached mirrors of those files for offline panel use.
Catalog YAML `icon:` fields point at the GitHub raw URLs.
